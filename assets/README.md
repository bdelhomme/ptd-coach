# Documents source institutionnels

Les quatre `.docx` originaux du PTD ne sont **pas inclus** dans l'historique Git initial. Voir `docs/REFERENCE_MATERIAL.md` pour leurs noms, leur contexte et un résumé sourcé.

Pour les utiliser ultérieurement, les stocker dans un espace institutionnel autorisé et référencer des identifiants de version ou sommes de contrôle. Ne pas les pousser automatiquement dans un dépôt distant, même privé.
