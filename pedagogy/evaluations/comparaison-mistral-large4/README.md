# Premier essai Large 4 interrompu

Un appel TX05 c2 s'est terminé par `mistral_invalid_response` ; la campagne a
stoppé immédiatement, sans relance. Le fichier JSONL conserve l'erreur et le
contexte fictif ; l'utilisation et la facturation de l'appel sont inconnues.
Un diagnostic distinct et sa consommation connue sont décrits dans
`docs/COMPARAISON_MODELES_MISTRAL.md`. La cause exacte de l'erreur n'est pas
établie et aucun jugement pédagogique n'est possible pour Large 4.
